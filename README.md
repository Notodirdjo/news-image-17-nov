A newspaper front page summing up the world's news of Tuesday 17 November
2026 in a single image: the Kerch Bridge attack and strikes on Kyiv, tankers
hit by mines near the Strait of Hormuz, the Xi–Trump–Putin meeting set for
Shenzhen, five European states' joint migrant return hub in Rwanda, and the
Pentagon's ninth straight failed audit — plus four more stories in the
"Also today" strip.

The image is drawn with Pillow from the verified facts in `draw.py`
(`python3 draw.py` re-renders `entry.png`); `main.py` copies it to the
make.fun output directory. Python 3.13 standard library only, no network.
